关于系统

📋 系统简介

系统名称：学生信息管理系统

版本号：v1.0.0

开发框架：Spring Boot 3.x + Vue 3 + Thymeleaf

数据库：MySQL 8.0 + Redis

消息队列：Apache Kafka

部署方式：Docker Compose

🎯 技术亮点

✓ 前后端分离：Vue3 SPA + Spring Boot RESTful API

✓ 模板引擎：Thymeleaf 渲染系统门户页面

✓ 安全认证：JWT Token + Spring Security

✓ 权限控制：RBAC 模型，支持动态权限管理

✓ 高性能排名：Redis ZSet 实现 O(log N) 复杂度排行榜

✓ 异步处理：Kafka 消息队列处理系统日志

✓ 接口监控：AOP 切面统计接口性能

✓ 容器化部署：Docker Compose 一键启动所有服务
