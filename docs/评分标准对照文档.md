**技术实现：**
```java
// 登录时存储 Token
public LoginResponse login(LoginRequest request) {
    // 1. 验证用户名密码
    Authentication authentication = authenticationManager.authenticate(...);
    
    // 2. 生成 JWT Token
    String token = jwtUtil.generateToken(username);
    
    // 3. 存储到 Redis
    String redisKey = "token:" + username;
    redisTemplate.opsForValue().set(redisKey, token, 24, TimeUnit.HOURS);
    
    return new LoginResponse(token, ...);
}

// 请求时验证 Token
public boolean validateToken(String token) {
    String username = jwtUtil.getUsernameFromToken(token);
    String redisKey = "token:" + username;
    String redisToken = redisTemplate.opsForValue().get(redisKey);
    return token.equals(redisToken);  // 验证 Redis 中的 Token
}

// 登出时清除 Token
public void logout(String username) {
    String redisKey = "token:" + username;
    redisTemplate.delete(redisKey);
}
```

- Value: JWT Token 字符串
- TTL: 86400 秒（24小时）

**优势：**
- 支持分布式部署
- 可以主动使 Token 失效（登出、修改密码）
- 性能高，查询速度快

#### 2.3 基于方法的权限控制（9分）✅

**评分标准：** 使用注解在方法级别控制权限，支持细粒度的权限管理。

**实现情况：**
- ✅ **@RequiresPermission 注解** - 自定义权限校验注解
- ✅ **AOP 切面拦截** - 使用 AspectJ 拦截带注解的方法
- ✅ **支持 AND/OR 逻辑** - 可以要求拥有所有权限或任意权限
- ✅ **应用于 Controller 方法** - 在接口方法上添加注解

**技术实现：**

**1. 自定义注解：**
```java
@Target({ElementType.METHOD, ElementType.TYPE})
@Retention(RetentionPolicy.RUNTIME)
public @interface RequiresPermission {
    String[] value();  // 需要的权限代码
    Logical logical() default Logical.AND;  // 逻辑关系
    
    enum Logical {
        AND,  // 必须拥有所有权限
        OR    // 拥有任意一个权限即可
    }
}
```

**2. AOP 切面：**
```java
@Aspect
@Component
public class PermissionAspect {
    
    @Around("@annotation(com.student.system.annotation.RequiresPermission)")
    public Object checkPermission(ProceedingJoinPoint joinPoint) throws Throwable {
        // 1. 获取注解信息
        RequiresPermission annotation = method.getAnnotation(RequiresPermission.class);
        String[] requiredPermissions = annotation.value();
        
        // 2. 获取当前用户的权限列表
        UserDetailsImpl userDetails = (UserDetailsImpl) authentication.getPrincipal();
        List<String> userPermissions = userDetails.getPermissions();
        
        // 3. 校验权限
        boolean hasPermission = checkPermissions(userPermissions, requiredPermissions, logical);
        
        if (!hasPermission) {
            throw new AccessDeniedException("权限不足");
        }
        
        // 4. 权限通过，执行方法
        return joinPoint.proceed();
    }
}
```

**3. 使用示例：**
```java

}

// 多个权限（AND 逻辑）
@RequiresPermission({"student:view", "student:edit"})
public Result<String> updateStudent(@RequestBody StudentDTO dto) {
    // 必须同时拥有 student:view 和 student:edit 权限
```

#### 1.2 使用 AOP + 内存实现（7分）✅

**评分标准：** 使用 AOP 切面拦截接口调用，统计数据存储在内存中。

**实现情况：**
- ✅ **@RequestMonitor 注解** - 自定义监控注解，标记需要监控的接口
- ✅ **RequestMonitorAspect 切面** - AOP 切面拦截带注解的方法
- ✅ **内存存储** - 统计数据临时存储在内存中（已实现）

**技术实现：**
```java
// 自定义注解
@Target(ElementType.METHOD)
@Retention(RetentionPolicy.RUNTIME)
public @interface RequestMonitor {
    String value();  // 接口名称
    String category() default "";  // 接口分类
}

// AOP 切面
@Aspect
@Component
public class RequestMonitorAspect {
    
    @Around("@annotation(requestMonitor)")
    public Object monitor(ProceedingJoinPoint joinPoint, RequestMonitor requestMonitor) {
        long startTime = System.currentTimeMillis();
        
        try {
            Object result = joinPoint.proceed();
            long duration = System.currentTimeMillis() - startTime;
            
            // 统计成功调用
            recordSuccess(requestMonitor.value(), duration);
            return result;
            
        } catch (Throwable e) {
            long duration = System.currentTimeMillis() - startTime;
            
            // 统计失败调用
            recordFailure(requestMonitor.value(), duration);
            throw e;
        }
    }
}
```

**得分理由：** 使用 AOP 切面实现了接口监控，支持内存存储。

```java
private void recordSuccess(String apiName, long duration) {
    String key = "api:stats:" + apiName;
    
    // 原子操作更新统计数据
    redisTemplate.opsForHash().increment(key, "count", 1);
    redisTemplate.opsForHash().increment(key, "successCount", 1);
    redisTemplate.opsForHash().increment(key, "totalDuration", duration);
    
    // 计算平均耗时
    Long count = (Long) redisTemplate.opsForHash().get(key, "count");
    Long totalDuration = (Long) redisTemplate.opsForHash().get(key, "totalDuration");
    double avgDuration = totalDuration.doubleValue() / count;
    redisTemplate.opsForHash().put(key, "avgDuration", avgDuration);
}
```

**得分理由：** 使用 Redis 存储统计数据，支持持久化和分布式部署。

```java
@GetMapping("/stats")
public Result<List<Map<String, Object>>> getStats() {
    List<Map<String, Object>> stats = new ArrayList<>();
    
    // 从 Redis 获取所有统计数据
    Set<String> keys = redisTemplate.keys("api:stats:*");
    for (String key : keys) {
        Map<Object, Object> data = redisTemplate.opsForHash().entries(key);
        
        Map<String, Object> stat = new HashMap<>();
        stat.put("apiName", key.replace("api:stats:", ""));
        stat.put("count", data.get("count"));
        stat.put("successCount", data.get("successCount"));
        stat.put("failureCount", data.get("failureCount"));
        stat.put("avgDuration", data.get("avgDuration"));
        
        stats.add(stat);
    }
    
    return Result.success(stats);
}
```
