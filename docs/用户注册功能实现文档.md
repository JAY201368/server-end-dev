# 用户注册功能全链路实现文档

## 概述

本文档说明了学生管理系统用户注册功能的完整实现，包括前端页面、API 接口、后端服务、数据验证和安全措施。

## 架构图

```
前端注册页面 (Register.vue)
    ↓
前端 API 调用 (authAPI.register)
    ↓
Axios 请求拦截器
    ↓
后端控制器 (AuthController.register)
    ↓
后端服务层 (AuthServiceImpl.register)
    ↓
数据验证 + 密码加密
    ↓
MyBatis Plus 插入数据库
    ↓
返回注册响应
```

## 一、后端实现

### 1. DTO 定义

**文件:** `backend/src/main/java/com/student/system/dto/RegisterRequest.java`

```java
@Data
public class RegisterRequest {
    @NotBlank(message = "用户名不能为空")
    @Size(min = 3, max = 20, message = "用户名长度必须在3-20个字符之间")
    @Pattern(regexp = "^[a-zA-Z0-9_]+$", message = "用户名只能包含字母、数字和下划线")
    private String username;

    @NotBlank(message = "密码不能为空")
    @Size(min = 6, max = 20, message = "密码长度必须在6-20个字符之间")
    private String password;

    @NotBlank(message = "确认密码不能为空")
    private String confirmPassword;

    @NotBlank(message = "昵称不能为空")
    @Size(min = 2, max = 20, message = "昵称长度必须在2-20个字符之间")
    private String nickname;

    @Email(message = "邮箱格式不正确")
    private String email;  // 可选

    @Pattern(regexp = "^1[3-9]\\d{9}$", message = "手机号格式不正确")
    private String phone;  // 可选
}
```

### 2. VO 定义

**文件:** `backend/src/main/java/com/student/system/vo/RegisterResponse.java`

```java
@Data
@NoArgsConstructor
@AllArgsConstructor
public class RegisterResponse {
    private Long userId;
    private String username;
    private String nickname;
    private String createTime;
}
```

### 3. 控制器接口

**文件:** `backend/src/main/java/com/student/system/controller/AuthController.java`

```java
/**
 * 用户注册
 */
@PostMapping("/register")
public Result<RegisterResponse> register(@Valid @RequestBody RegisterRequest registerRequest) {
    log.info("用户注册请求: {}", registerRequest.getUsername());
    RegisterResponse response = authService.register(registerRequest);
    return Result.success("注册成功", response);
}
```

**接口路径:** `POST /api/auth/register`

### 4. 服务层实现

**文件:** `backend/src/main/java/com/student/system/service/impl/AuthServiceImpl.java`

#### 注册业务流程：

1. **验证两次密码是否一致**
   ```java
   if (!password.equals(confirmPassword)) {
       throw new BadCredentialsException("两次密码不一致");
   }
   ```

2. **检查用户名是否已存在**
   ```java
   LambdaQueryWrapper<SysUser> wrapper = new LambdaQueryWrapper<>();
   wrapper.eq(SysUser::getUsername, username);
   Long count = userMapper.selectCount(wrapper);
   if (count > 0) {
       throw new BadCredentialsException("用户名已存在");
   }
   ```

3. **检查邮箱是否已被注册（如果提供）**
   ```java
   if (registerRequest.getEmail() != null && !registerRequest.getEmail().isEmpty()) {
       // 检查邮箱唯一性
   }
   ```

4. **检查手机号是否已被注册（如果提供）**
   ```java
   if (registerRequest.getPhone() != null && !registerRequest.getPhone().isEmpty()) {
       // 检查手机号唯一性
   }
   ```

5. **创建新用户并加密密码**
   ```java
   SysUser newUser = new SysUser();
   newUser.setUsername(username);
   newUser.setPassword(passwordEncoder.encode(password)); // BCrypt 加密
   newUser.setNickname(nickname);
   newUser.setEmail(registerRequest.getEmail());
   newUser.setPhone(registerRequest.getPhone());
   newUser.setStatus(1); // 默认启用
   ```

6. **插入数据库**
   ```java
   int rows = userMapper.insert(newUser);
   if (rows == 0) {
       throw new RuntimeException("用户注册失败");
   }
   ```

7. **返回注册响应**
   ```java
   return new RegisterResponse(
       newUser.getId(),
       newUser.getUsername(),
       newUser.getNickname(),
       newUser.getCreateTime().format(formatter)
   );
   ```

### 2. API 接口封装

**文件:** `frontend/src/api/index.js`

```javascript
export const authAPI = {
  login(username, password) {
    return request.post('/auth/login', { username, password })
  },

  register(username, password, confirmPassword, nickname, email, phone) {
    return request.post('/auth/register', {
      username,
      password,
      confirmPassword,
      nickname,
      email,
      phone
    })
  }
}
```

### 3. 路由配置

**文件:** `frontend/src/router/index.js`

```javascript
const routes = [
  {
    path: '/login',
    name: 'Login',
    component: Login
  },
  {
    path: '/register',
    name: 'Register',
    component: Register
  },
  // ... 其他路由
]

// 路由守卫：注册页面无需登录即可访问
router.beforeEach((to, from, next) => {
  const token = localStorage.getItem('token')
  const publicPages = ['/login', '/register']
  const authRequired = !publicPages.includes(to.path)

  if (authRequired && !token) {
    next('/login')
  } else if ((to.path === '/login' || to.path === '/register') && token) {
    next('/dashboard')
  } else {
    next()
  }
})
```

## 三、安全措施

### 1. 密码安全

- **前端验证：**
  - 密码长度限制（6-20字符）
  - 两次密码必须一致

- **后端加密：**
  - 使用 BCrypt 算法加密密码
  - 永远不存储明文密码
  ```java
  newUser.setPassword(passwordEncoder.encode(password));
  ```

### 2. 数据验证

- **前端验证：**
  - 实时表单验证（Element Plus）
  - 用户名格式验证（正则表达式）
  - 邮箱格式验证
  - 手机号格式验证

- **后端验证：**
  - Jakarta Validation 注解验证
  - 业务逻辑验证（用户名/邮箱/手机号唯一性）
  - 事务保证数据一致性

### 3. 防止重复注册

- 用户名唯一性检查
- 邮箱唯一性检查（如果提供）
- 手机号唯一性检查（如果提供）

### 2. 验证功能

**测试场景：**

- 密码字段为 BCrypt 加密的哈希值（以 `$2a$10$` 开头）
