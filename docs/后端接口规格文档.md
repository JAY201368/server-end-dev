## 1. 概述

### 1.1 基本信息

- **后端框架**: Spring Boot 3.x + Spring Security 6.x
- **数据库**: MySQL 8.0 + Redis
- **API 风格**: RESTful
- **数据格式**: JSON
- **字符编码**: UTF-8
- **认证方式**: JWT (JSON Web Token)

### 1.2 基础配置

- **Base URL**: `http://localhost:8080`
- **Content-Type**: `application/json`
- **跨域配置 (CORS)**:
  - 允许源: `http://localhost:*`, `http://127.0.0.1:*`
  - 允许方法: GET, POST, PUT, DELETE, OPTIONS, PATCH
  - 允许头: 所有 (*)
  - 允许凭证: true
  - 预检请求有效期: 3600 秒
  - 暴露响应头: Authorization, Content-Type

## 2. 统一响应格式

所有接口均使用统一的响应格式 `Result<T>`：

```json
{
  "code": 200,
  "message": "操作成功",
  "data": {},
  "timestamp": 1704067200000
}
```

### 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| code | Integer | 状态码，200 表示成功，500 表示失败 |
| message | String | 响应消息，描述操作结果 |
| data | T | 响应数据，泛型类型，可为任意类型 |
| timestamp | Long | 时间戳（毫秒） |

## 3. 认证与授权

### 3.1 认证机制

- 使用 **JWT (JSON Web Token)** 进行身份认证
- 登录成功后，后端返回 token
- 前端需在请求头中携带 token：`Authorization: Bearer <token>`

### 3.2 公开接口（无需认证）

以下接口无需携带 token 即可访问：

| 路径模式 | 说明 |
|----------|------|
| `/health/**` | 健康检查端点 |
| `/actuator/**` | Spring Boot Actuator 端点 |
| `/auth/login` | 用户登录 |
| `/auth/register` | 用户注册 |
| `/test/password` | 密码测试（仅用于调试） |
| `/student/**` | 学生管理接口（开发阶段临时放行，生产环境应加权限控制） |
| `/score/**` | 成绩管理接口（开发阶段临时放行，生产环境应加权限控制） |
| `/monitor/**` | 监控接口（开发阶段临时放行，生产环境建议添加权限控制） |

### 3.3 受保护接口

需要认证的接口：

| 路径 | 需要权限 |
|------|----------|
| `/auth/logout` | 已认证用户 |
| `/auth/info` | 已认证用户 |
| `/test/admin` | ROLE_ADMIN |
| `/test/teacher` | ROLE_TEACHER |
| `/test/student` | ROLE_STUDENT |
| `/test/authenticated` | 已认证用户 |

### 3.4 安全配置

- **CSRF**: 已禁用（使用 JWT，无需 CSRF 保护）
- **Session**: STATELESS（无状态，不使用 Session）
- **密码加密**: BCrypt
- **JWT 过滤器**: 在 `UsernamePasswordAuthenticationFilter` 之前执行

## 4. 接口列表

### 4.1 认证模块 (AuthController)

**Base Path**: `/auth`

#### 4.1.1 用户登录

- **路径**: `POST /auth/login`
- **描述**: 用户登录，验证用户名和密码，返回 JWT token
- **访问权限**: 公开（无需认证）
- **请求体**:

```json
{
  "username": "admin",
  "password": "123456"
}
```

**请求参数 (LoginRequest)**:

| 字段 | 类型 | 必填 | 校验规则 | 说明 |
|------|------|------|----------|------|
| username | String | 是 | @NotBlank | 用户名 |
| password | String | 是 | @NotBlank | 密码 |

- **响应示例**:

```json
{
  "code": 200,
  "message": "登录成功",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "tokenType": "Bearer",
    "userId": 1,
    "username": "admin",
    "nickname": "管理员",
    "roles": ["ROLE_ADMIN"],
    "permissions": ["system:user:view", "system:user:edit"]
  },
  "timestamp": 1704067200000
}
```

**响应数据 (LoginResponse)**:

| 字段 | 类型 | 说明 |
|------|------|------|
| token | String | JWT token，用于后续请求认证 |
| tokenType | String | Token 类型，固定为 "Bearer" |
| userId | Long | 用户 ID |
| username | String | 用户名 |
| nickname | String | 昵称 |
| roles | List\<String\> | 角色列表 |
| permissions | List\<String\> | 权限列表 |

---

#### 4.1.2 用户注册

- **路径**: `POST /auth/register`
- **描述**: 用户注册，创建新用户账号
- **访问权限**: 公开（无需认证）
- **请求体**:

```json
{
  "username": "newuser",
  "password": "password123",
  "confirmPassword": "password123",
  "nickname": "新用户",
  "email": "newuser@example.com",
  "phone": "13800138000"
}
```

**请求参数 (RegisterRequest)**:

| 字段 | 类型 | 必填 | 校验规则 | 说明 |
|------|------|------|----------|------|
| username | String | 是 | @NotBlank, @Size(3-20), @Pattern(^[a-zA-Z0-9_]+$) | 用户名，3-20 字符，仅字母数字下划线 |
| password | String | 是 | @NotBlank, @Size(6-20) | 密码，6-20 字符 |
| confirmPassword | String | 是 | @NotBlank | 确认密码，需与密码一致 |
| nickname | String | 是 | @NotBlank, @Size(2-20) | 昵称，2-20 字符 |
| email | String | 否 | @Email | 邮箱，需符合邮箱格式 |
| phone | String | 否 | @Pattern(^1[3-9]\\d{9}$) | 手机号，11 位数字，1 开头 |

- **响应示例**:

```json
{
  "code": 200,
  "message": "注册成功",
  "data": {
    "userId": 10,
    "username": "newuser",
    "nickname": "新用户",
    "createTime": "2024-01-01 12:00:00"
  },
  "timestamp": 1704067200000
}
```

**响应数据 (RegisterResponse)**:

| 字段 | 类型 | 说明 |
|------|------|------|
| userId | Long | 用户 ID |
| username | String | 用户名 |
| nickname | String | 昵称 |
| createTime | String | 注册时间 |

---

#### 4.1.3 用户登出

- **路径**: `POST /auth/logout`
- **描述**: 用户登出，清除用户会话
- **访问权限**: 需要认证
- **请求头**: `Authorization: Bearer <token>`

- **响应示例**:

```json

}
```

#### 4.2.3 删除学生

- **路径**: `DELETE /student/{id}`
- **描述**: 删除学生（逻辑删除），并发送删除事件到 Kafka
- **访问权限**: 公开（开发阶段）
- **监控注解**: `@RequestMonitor("删除学生", category="student")`
- **路径参数**:

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | Long | 是 | 学生 ID |

- **请求示例**: `DELETE /student/1`
- **响应示例**:

```json
{
  "code": 200,
  "message": "删除学生成功",
  "data": null,
  "timestamp": 1704067200000
}
```

**备注**:
- 使用 MyBatis-Plus 的逻辑删除功能（@TableLogic）
- 删除成功后，会发送删除事件到 Kafka topic: `system-log-topic`
- Kafka 消息包含操作人、IP 地址、目标学生信息等

### 4.3 成绩管理模块 (ScoreController)

**Base Path**: `/score`

**注意**: 当前开发阶段临时放行所有接口，生产环境应添加权限控制。

**核心特性**:
- MySQL + Redis 双存储模型
- Redis ZSet 实现高性能排行榜（时间复杂度 O(log N)）
- 学期维度数据组织

#### 4.3.1 录入成绩

- **路径**: `POST /score/save`
- **描述**: 录入新成绩，同时写入 MySQL 和 Redis ZSet
- **访问权限**: 公开（开发阶段）
- **监控注解**: `@RequestMonitor("录入成绩", category="score")`
- **请求体**:

```json
{
  "studentId": 1,
  "courseId": 101,
  "score": 95.5,
  "semester": "2024-1",
  "examDate": "2024-06-15",
  "remark": "期末考试"
}
```

**请求参数 (ScoreDTO)**:

| 字段 | 类型 | 必填 | 校验规则 | 说明 |
|------|------|------|----------|------|
| studentId | Long | 是 | @NotNull | 学生 ID |
| courseId | Long | 是 | @NotNull | 课程 ID |
| score | BigDecimal | 是 | @NotNull, @DecimalMin(0.00), @DecimalMax(100.00) | 成绩分数，0-100 |
| semester | String | 是 | @NotBlank | 学期，例如 "2024-1" |
| examDate | LocalDate | 否 | - | 考试日期 |
| remark | String | 否 | - | 备注 |

- **响应示例**:

```json
{
  "code": 200,
  "message": "成绩录入成功",
  "data": null,
  "timestamp": 1704067200000
}
```

**备注**:
- 检查该学生在该课程该学期是否已有成绩
- 同时写入 MySQL 数据库和 Redis ZSet
- Redis Key 格式: `score:ranking:{semester}`

## 6. 错误码说明

| 状态码 | 说明 |
|--------|------|
| 200 | 操作成功 |
| 400 | 请求参数错误（通常由 @Valid 校验失败触发） |
| 401 | 未认证（未登录或 token 无效） |
| 403 | 无权限（已认证但权限不足） |
| 404 | 资源不存在 |
| 500 | 服务器内部错误 |

### 6.1 常见错误消息

| 错误消息 | 说明 | 解决方案 |
|----------|------|----------|
| "用户名不能为空" | 登录或注册时用户名为空 | 确保请求体包含 username 字段 |
| "学号已存在" | 添加学生时学号重复 | 使用不同的学号 |
| "学生不存在" | 查询或操作的学生 ID 不存在 | 检查学生 ID 是否正确 |
| "该学生在该课程该学期的成绩已存在" | 重复录入成绩 | 使用更新接口而非录入接口 |
| "未登录" | 访问需要认证的接口时未携带 token | 先调用登录接口获取 token |
| "权限不足" | 用户角色不满足接口要求 | 使用具有相应权限的账号 |

## 7. 附加说明

### 7.1 监控功能

使用 `@RequestMonitor` 注解的接口会自动记录以下统计信息：
- 调用次数
- 成功/失败次数
- 平均响应时间

统计信息存储在 Redis 中，可通过监控接口查询。

**已监控的接口**:
1. `POST /student/add` - 添加学生
2. `DELETE /student/{id}` - 删除学生
3. `GET /student/list` - 查询学生列表
4. `POST /score/save` - 录入成绩
5. `GET /score/ranking` - 查询成绩排行榜

### 7.2 Kafka 集成

删除学生操作会发送事件到 Kafka:
- **Topic**: `system-log-topic`
- **消息格式**: JSON
- **包含字段**: 操作类型、操作人、目标 ID、目标信息、操作时间、IP 地址、备注

### 7.3 Redis 应用场景

1. **成绩排行榜**: 使用 ZSet 存储，Key 格式 `score:ranking:{semester}`
2. **API 统计**: 存储接口调用统计信息
3. **缓存**: （可扩展）用户信息、热点数据等

### 7.4 MyBatis-Plus 特性

1. **逻辑删除**: 学生实体使用 `@TableLogic` 注解，删除操作实际是更新 deleted 字段
2. **自动填充**: createTime 和 updateTime 字段自动填充
3. **分页查询**: 使用 `IPage` 接口实现分页

### 7.5 生产环境建议

1. **权限控制**: 为 `/student/**`、`/score/**`、`/monitor/**` 添加角色权限限制
2. **禁用测试接口**: 删除或禁用 `/test/**` 接口
3. **HTTPS**: 启用 HTTPS 保护数据传输
4. **限流**: 添加接口限流保护
5. **日志脱敏**: 敏感信息（密码、手机号等）需脱敏处理
6. **监控告警**: 接入 APM 系统，监控接口性能和错误率

## 8. 前端对接指南

### 8.1 认证流程

1. 用户在登录页输入用户名和密码
2. 调用 `POST /auth/login` 接口
3. 后端返回 token，前端保存到 localStorage 或 sessionStorage
4. 后续所有请求在 Header 中携带：`Authorization: Bearer <token>`
5. 登出时调用 `POST /auth/logout`，并清除本地 token

### 8.2 请求拦截器示例 (Axios)

```javascript
import axios from 'axios'

// 创建 axios 实例
const request = axios.create({
  baseURL: 'http://localhost:8080',
  timeout: 10000
})

// 请求拦截器 - 添加 token
request.interceptors.request.use(
  config => {
    const token = localStorage.getItem('token')
    if (token) {
      config.headers['Authorization'] = `Bearer ${token}`
    }
    return config
  },
  error => {
    return Promise.reject(error)
  }
)

// 响应拦截器 - 统一处理错误
request.interceptors.response.use(
  response => {
    const res = response.data
    if (res.code !== 200) {
      // 错误提示
      alert(res.message || '请求失败')
      return Promise.reject(new Error(res.message || '请求失败'))
    }
    return res
  },
  error => {
    if (error.response && error.response.status === 401) {
      // token 失效，跳转登录页
      localStorage.removeItem('token')
      window.location.href = '/login'
    }
    return Promise.reject(error)
  }
)

export default request
```
